# Tech Context

## Technologies Used
*   **Frontend Framework:** Next.js (App Router)
*   **Static Site Generation (SSG):** Achieved via Server Components and `generateStaticParams`.
*   **Headless CMS:** WordPress (serving content via REST API).
*   **Styling:** Tailwind CSS with DaisyUI components.
*   **Development Language:** TypeScript.

## Development Setup
*   **Local Environment:** Next.js development server.
*   **Version Control:** Git.
*   **Code Editor:** VS Code.

## Technical Constraints
*   **Performance:** Optimized for fast loading times through SSG.
*   **Security:** Standard Next.js and WordPress security practices.
*   **Compatibility:** Responsive design using Tailwind CSS and DaisyUI.

## Dependencies
*   Next.js project setup.
*   Tailwind CSS and DaisyUI installed and configured.
*   WordPress instance accessible via REST API.

## Tool Usage Patterns
*   Utilizing Next.js `generateStaticParams` for SSG.
*   Fetching data from WordPress REST API within Server Components.
*   Applying Tailwind CSS and DaisyUI for component styling.
